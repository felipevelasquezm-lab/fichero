Configuración

Con Supabase, las fichas quedan guardadas en un servidor real (no solo en este navegador), con respaldo automático y control de acceso por login. El plan gratuito alcanza sobradamente para un hotel.

1. Crea un proyecto gratis en supabase.com.
2. En el editor SQL de tu proyecto, ejecuta este script para crear la tabla y las reglas de seguridad:

3. En tu proyecto Supabase, ve a Authentication → agrega un usuario (email/clave) por cada recepcionista.
4. Pega aquí tu URL y tu clave anon/public (Settings → API):

Al conectar, se te pedirá iniciar sesión con el email/clave que creaste en Supabase Authentication.

Sobre las fotos: en este prototipo la foto se guarda comprimida dentro de la misma ficha (columna foto_base64), simple para partir. Si el hotel lo adopta en serio, lo ideal es migrar las fotos a Supabase Storage (bucket privado) en vez de guardarlas como texto.

Exportar descarga todas las fichas en un archivo JSON (respaldo completo, reimportable) y también puedes exportar a CSV para abrir en Excel (doble clic en "Exportar").

Importar lee un archivo JSON exportado previamente y restaura las fichas — útil si cambias de computador o quieres migrar de modo local a Supabase.

Recomendación: si trabajas en modo local, exporta un respaldo cada cierto tiempo y guárdalo aparte (Drive, correo, USB).
